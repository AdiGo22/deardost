# DearDost – AI powered conversation starter App

DearDost is an app made on ReactNative using Expo that helps user to boost their conversations with AI powered conversation starters depending on mood of the conversation. It is a great app to complement dating /social medial apps

##  Features
- fetching responses from Open AI GPT-4o mini model
- Mood Based Conversation Starter, new and refreshing on every click
- Styled using Nativewind
- Build with latest EAS to avoid crashes and real time app updates

## 🛠️ Tech Stack

- **Frontend**: React Native (TypeScript), Expo, NativeWind
- **API Integration**: OpenAI GPT
- **Deployment**: EAS Build

## 📦 Installation & Setup

1. **Clone the Repository**

```bash
git clone https://github.com/YourUsername/cine-app.git
cd deardost
```
2. Install Dependencies

```bash
npm install
Set Up Environment Variables
```
3. Start the App
```bash
npx expo start
Scan the QR code with Expo Go on your phone (iOS or Android)
Or launch it in an Android/iOS simulator
```
